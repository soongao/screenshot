# Chromium Browser Extension

用于让截图工具在浏览器页面内识别精确的滚动容器，而不是只按整窗或像素区域猜测。

## 加载方式

1. 打开 Chromium 浏览器的扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择当前目录 `browser-extension/chromium`。

## 使用方式

1. 启动桌面截图应用。
2. 在应用里进入 `滚动截图`。
3. 切回浏览器页面。
4. 将鼠标移动到页面中的可滚动区域上。
5. 扩展会识别并高亮最合适的滚动容器。
6. 单击后自动开始滚动采集。
7. 到底部后会自动结束，并回到桌面端生成长图。
